# 🐼 판다마켓 – 랜딩/로그인/회원가입 페이지 구현

> Codeit 풀스택 스프린트 – 미션 1, 미션 2 통합
> HTML, CSS를 활용하여 판다마켓의 핵심 페이지 UI를 구현하고 Netlify로 배포한 프로젝트입니다.

---

## 🔎 프로젝트 개요

이 프로젝트는 피그마의 정보를 바탕으로 하여, HTML과 CSS로  
판다마켓의 랜딩 페이지 / 로그인 페이지 / 회원가입 페이지를 구현한 미션입니다.

또한,

- 사이트 배포(Netlify)
- 구글 애널리틱스를 통한 방문자 수 추적
- 외 미션 1, 2 기본 요구 사항

위와 같은 요구사항을 하나씩 실현하며, 실력을 다지는 과정이었습니다.

---

## 🚀 배포 링크

🔗 **https://pandamarket-jj.netlify.app/**

## 📂 구현한 페이지

| 페이지      | 경로       | 설명                                                   |
| ----------- | ---------- | ------------------------------------------------------ |
| 랜딩 페이지 | `/`        | 판다마켓 소개, 버튼, 히어로섹션, features 섹션, footer |
| 로그인      | `/login`   | 이메일/비밀번호 입력 & SNS 로그인 아이콘               |
| 회원가입    | `/signup`  | 이메일·비밀번호·비밀번호 확인 입력                     |
| FAQ         | `/faq`     | 빈 페이지                                              |
| Privacy     | `/privacy` | 빈 페이지                                              |

## ✨ 주요 기능 & 구현 포인트

### 🖥 메인 페이지

- 상단 네비게이션 바(GNB) 스크롤 고정
- 로고 클릭 시 `/` 이동
- “구경하러 가기” → `/items` 이동
- “로그인” 버튼 → `/login` 이동
- SNS 아이콘 클릭 시 새 창에서 각각 홈페이지로 이동
- 1920px 이상일 때 배경 전체 너비 채움 + 내부 요소 가운데 정렬
- 1920px 이하일 때 내부 요소들의 여백 200px 규칙 유지
- 푸터도 동일 규칙으로 정렬 유지

---

### 🔐 로그인 / 회원가입 페이지

- input focus 시 파란 테두리(#3692FF)
- focus out 시 테두리 제거
- 비밀번호 보기용 눈 아이콘 추가
- 회원가입/로그인 간 내부 링크 이동 정상 동작

---

### 🧰 공통

- reset.css 적용
- CSS 변수로 color palette 관리
- 구글 애널리틱스 설치(G-EZD15B2SM6)
  -> 배포한 사이트에서 페이지 검사 - html - head tag - G로 시작하는 코드 확인
  -> 구글 애널리틱스에서 실시간 유입 확인
